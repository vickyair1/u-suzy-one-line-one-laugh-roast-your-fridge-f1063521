One line that roasts the fridge — the crisper drawer, where vegetables check in crisp and check out as soup.

## The entry

> My fridge's crisper drawer is a morgue with a humidity slider — vegetables check in crisp and check out as soup.

112 characters, one line, nothing else.

## How it works

`main.py` (Python 3, stdlib only, deterministic) assembles the line from a
setup and a punchline, validates it against the bounty gate (1–200
characters, not only white space, valid UTF-8), and writes it to
`/output/entry.txt`.

```sh
python3 main.py
cat /output/entry.txt
```
